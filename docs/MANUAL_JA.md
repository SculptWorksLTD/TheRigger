# The Rigger — マニュアル

## できること

The Rigger は、無線機とパソコンのソフトをつなぐ交換台です。ふつう無線機のシリアルポートは一度に 1 つのソフトしか使えません。The Rigger だけが無線機と通信し、各ソフトに専用の接続を用意します。そのため WSJT-X、ログソフト、コンテストソフトなどが同じ無線機を同時に使っても、互いに邪魔をしません。

複数の無線機を同時に扱えます。Windows と macOS で動作します。

## インストール

GitHub のプロジェクトの **Releases** ページから、お使いのシステム用のファイルをダウンロードします。

- **Windows**：`therigger-windows-amd64.exe` を実行します。「Windows によって PC が保護されました」と表示されたら、*詳細情報 › 実行* を選びます。
- **macOS**：`TheRigger-macOS-arm64.zip`（Apple シリコンの Mac）または `TheRigger-macOS-amd64.zip`（Intel Mac）を展開し、*The Rigger* をアプリケーションフォルダに移します。初回は右クリック › *開く*。

以後、The Rigger は自動でアップデートし、パソコンの起動時に自動で起動します。

## 初回起動

起動するとクレジット付きのようこそ画面が表示されます。**はじめる · 73** を押してください。

無線機を USB ケーブルでつなぎ、電源を入れます。数秒で The Rigger が自動で認識します。USB ポート、プロトコル、通信速度を試し、機種を判別します。設定は何も要りません。

## ウィンドウ

ウィンドウには必要なことだけが表示されます。

- **無線機ごとに 1 行**とランプ：無線機が接続されて応答していれば緑、電源が切れているかケーブルが外れていれば灰色。
- **各無線機の下に、接続中のソフト**とそれぞれのランプ：無線機と通信中なら緑、ポートを開いているが動いていなければ黄色。

無線機の下に「接続中のソフトなし」と表示されていれば、どのソフトも使っていません。

上部に 3 つのボタンがあります：**?**（ソフトの接続方法とこのマニュアル）、**⚙**（設定）、**⏻**（The Rigger を終了）。

ウィンドウを閉じても The Rigger は止まりません。時計の近くの通知領域に残り、ソフトは接続されたままです。再び開くにはアイコンをクリックして *ウィンドウを表示* を選びます。

## ソフトの接続

**?** を押すと、ソフトごとに設定すべき内容が、割り当て済みのポートとともに表示されます。**コピー** ボタンでポート名またはアドレスをコピーし、ソフトに貼り付けます。

接続方法は 2 種類です。

1. **Hamlib NET rigctl**：WSJT-X、JTDX、JS8Call、fldigi、CQRLOG など対応ソフト用。ソフトで無線機に *Hamlib NET rigctl* を、サーバーに表示されたアドレス（例：`127.0.0.1:4532`）を選びます。いくつのソフトでも接続できます。
2. **シリアルポート**：Log4OM、N1MM Logger+、HRD、Logger32、DXLab Commander、MixW などそのほかのソフト用。ソフトで無線機に **お使いの無線機の実際の機種**（例：Icom IC-7100）または **Kenwood TS-2000** を、ポートに表示されたものを選びます。速度は任意、フロー制御なし、PTT は CAT。
   - Windows では通常の `COM` ポートです。
   - Mac では `/tmp/TheRigger/` にあります（例：`/tmp/TheRigger/IC-7100-1`）。

**自動判別**：各ポートはソフトのプロトコル（Icom CI-V、Kenwood、Elecraft、Yaesu、FT-817、TS-2000）を自動で判別します。ソフトで実際の機種を選ぶと、コマンドは無線機に直接届き、その無線機のすべての機能が使えます。Kenwood TS-2000 を選ぶと、周波数・モード・PTT・スプリットの共通機能が使えます。Yaesu の無線機では、TS-2000 に設定したソフトがポートを初めて使うとき、最初の送信で PTT が効かないことがあります。2 回目からは動作し、ポートがそれを記憶します。

1 つのポートに 1 つのソフト。ポートは衝突しないよう The Rigger が割り当て済みです。無線機ごとに 4 ポートあり、設定で最大 16 まで増やせます。

### 設定例

- **WSJT-X**：*設定 › 無線機*：Rig *Hamlib NET rigctl*、Network Server *127.0.0.1:4532*、PTT *CAT*。
- **Log4OM**：CAT 設定で、Log4OM 用に表示されたポートの *Kenwood TS-2000* を選びます。OmniRig はもう不要です。
- **N1MM Logger+**：*Config › Configure Ports*：Radio *Kenwood TS-2000*、N1MM 用に表示された COM ポート、速度は任意、*DTR* と *RTS* はオフ。

## 設定

- **言語**：自動（システムの言語）または 7 言語から選択。
- **自動起動**：パソコンの起動時に The Rigger が自動で起動します。
- **自動アップデート**：新しいバージョンは、どのソフトも無線機を使っていないときに自動でインストールされます。
- **USB ドライバー自動導入**：足りない USB ドライバーを自動でインストールします。
- **無線機ごとのポート数**：1〜16。すぐに反映されます。使用中のポートが外されることはありません。

## USB ドライバー

- **Windows**：ドライバーのない無線機をつなぐと、The Rigger が Windows Update（またはメーカー）から署名済みの公式ドライバーをダウンロードしてインストールします。Windows の確認が 1 回表示されます。対象は Silicon Labs（Icom、Yaesu、Kenwood）、FTDI（Elecraft と多くのケーブル）、WCH CH340（Xiegu と廉価なケーブル）、Prolific です。
- **macOS**：ドライバーはシステムに含まれています。

Windows の仮想 COM ポートは無料の *com0com* ドライバーを使います。初回に The Rigger が自動でインストールします（Windows の確認が 1 回あります）。

## 対応無線機

- **Icom** と CI-V 互換機（Xiegu も含む）：IC-7100、IC-7300、IC-705、IC-7610、IC-9700、IC-905、IC-7760 など。
- **Kenwood**：TS-2000、TS-480、TS-590S/SG、TS-890S、TS-990S。
- **Elecraft**：K3、KX2、KX3、K4。
- 最近の **Yaesu**：FT-991/A、FTDX10、FT-710、FTDX101、FT-891、FTDX3000 など。
- 従来の **Yaesu**：FT-817、FT-818、FT-857、FT-897。
- Kenwood 互換コマンドのその他の無線機：Lab599 TX-500、QRP Labs QDX/QMX、多くの SDR。

## よくある問題

- **無線機が表示されない**：電源が入り、USB ケーブルでつながっているか確認してください。Icom では無線機のメニューの *CI-V USB* ボーレートを *Auto* または通常の値にします。*CI-V USB Echo Back* はそのままでかまいません。
- **ソフトが接続できない**：**?** を押し、*Kenwood TS-2000*（または *Hamlib NET rigctl*）と正しいポートを選んだか確認してください。2 つのソフトで同じシリアルポートは使えません。
- **ソフトのランプが黄色**：ソフトがポートを開いていますが、無線機に問い合わせていません。ソフトで CAT が有効か確認してください。
- **Windows で COM ポートが作成されない**：Windows 11 の一部の PC では *com0com* ドライバーがブロックされることがあります。その場合は、常に使える *Hamlib NET rigctl* 接続を使ってください。
